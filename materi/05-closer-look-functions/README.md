# ✈️ Modul 05: A Closer Look at Functions

Selamat datang di **Modul 05**! Modul ini membawa pemahaman fungsionalitas JavaScript & TypeScript ke level yang lebih dalam (*advanced functions*).

Sepanjang modul ini, kita akan menggunakan studi kasus nyata: **Sistem Pemesanan Tiket Maskapai Penerbangan (Flight Booking)** dan **Pencatatan Counter Interaktif**.

---

## 🗺️ Peta Materi

```text
materi/05-closer-look-functions/
├── 01-default-parameter-lanjutan/    # Default parameter berbasis ekspresi & parameter lain
├── 02-passing-arguments-value-vs-ref/# Passing by Value vs Reference + Readonly<T>
├── 03-first-class-dan-higher-order/  # Fungsi sebagai warga kelas satu (First-Class Citizens)
├── 04-fungsi-menerima-callback/      # Abstraksi kode dengan fungsi callback
├── 05-fungsi-mengembalikan-fungsi/   # Higher-order function tingkat lanjut & Currying
├── 06-call-dan-apply/                # Manipulasi manual keyword `this` (call vs apply)
├── 07-bind/                          # Mengikat `this`, Partial Application, & Event Handler
├── 08-iife/                          # Immediately Invoked Function Expressions (IIFE)
├── 09-closure-dasar/                 # Konsep Closure & Diagram Scope execution context
├── 10-closure-lanjutan/              # Studi kasus closure: Timer, Data Privat & Factory
├── 11-bonus-generics-dasar/          # Bonus TS: Pengenalan Type Generics <T> pada Fungsi
└── 12-challenge-aplikasi-polling/    # Tantangan: Sistem Aplikasi Polling Suara Interaktif
```

## ▶️ Cara Belajar & Menjalankan Kode

1. Masuk ke folder pelajaran yang ingin dipelajari, baca `README.md`.
2. Jalankan contoh kode:
   ```bash
   npm run materi -- materi/05-closer-look-functions/01-default-parameter-lanjutan/contoh.ts
   ```
3. Kerjakan `latihan.ts` dan jalankan:
   ```bash
   npm run materi -- materi/05-closer-look-functions/01-default-parameter-lanjutan/latihan.ts
   ```
4. Cocokkan jawabanmu dengan `solusi.ts`.
