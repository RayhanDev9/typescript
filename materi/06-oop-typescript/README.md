# 🏛️ Modul 06: Object-Oriented Programming (OOP) dengan TypeScript

Selamat datang di **Modul 06**! Modul ini membahas paradigma **Pemrograman Berorientasi Objek (Object-Oriented Programming)** secara komprehensif menggunakan sintaks modern TypeScript dan JavaScript.

Sepanjang modul ini, kita akan membangun model sistem nyata, mulai dari kendaraan, pengguna, hingga puncaknya pada **Sistem Pengelolaan Rekening Bank (Bankist System)**.

---

## ▶️ Cara Belajar & Menjalankan Kode

1. Buka folder pelajaran yang ingin dipelajari, baca `README.md`.
2. Jalankan contoh kode:
   ```bash
   npm run materi -- materi/06-oop-typescript/04-class-dan-constructor/contoh.ts
   ```
3. Kerjakan `latihan.ts` dan jalankan:
   ```bash
   npm run materi -- materi/06-oop-typescript/04-class-dan-constructor/latihan.ts
   ```
4. Cocokkan jawabanmu dengan `solusi.ts`.
